노래만 잘라주는 가위

긴 녹음에서 노래만 찾아 곡별로 잘라 드려요. 노래 이름도 붙여 드려요.

녹음을 받을 준비가 됐어요 방금 보낸 녹음은 최근 항목 맨 위의 노래가위 녹음 파일이에요.

음성 메모에서 바로 보내기

  1. 음성 메모에서 녹음 → ⋯ → 공유 → 파일에 저장
  2. 위 녹음 선택 → 최근 항목 맨 위의 녹음
자주 쓴다면 · 단축어로 더 빠르게

처음 한 번만 추가해 두면, 공유 메뉴에서 바로 이 페이지로 보낼 수 있어요.

단축어 추가
  1. 음성 메모에서 녹음 → ⋯ → 공유 → 노래 가위로 보내기
  2. 이 페이지가 열리면 보낸 녹음 고르기

음성 메모에서 가져오기

음성 메모 앱에서 녹음을 이 창으로 끌어다 놓으세요.

파일 선택 창에서 찾기
  1. 녹음 선택을 누르고 ⌘⇧G
  2. 이 경로를 붙여넣고 ↩ ~/Library/Group Containers/group.com.apple.VoiceMemos.shared/Recordings
  3. 파일 이름이 녹음한 날짜·시각이에요. 시각으로 고르세요.

녹음은 이 기기에서만 처리돼요. 노래 이름을 찾을 때만 곡마다 15초를 음악 인식 서비스(AudD)로 보내요.
